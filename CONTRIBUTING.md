# Contributing to NotionMind

Thank you for your interest in contributing to NotionMind! We welcome all kinds of contributions to make this project better for everyone.

## How to Contribute

- **Report Bugs:**

  - Open an issue describing the bug, steps to reproduce, and expected behavior.
  - Include logs, screenshots, or error messages if possible.

- **Suggest Features:**

  - Open an issue with the `enhancement` label.
  - Describe your idea, use case, and any relevant context.

- **Submit Pull Requests:**
  1. Fork the repository
  2. Create a new branch (`git checkout -b feature/your-feature-name`)
  3. Make your changes with clear, descriptive commit messages
  4. Ensure your code passes all tests (`mix test`)
  5. Open a pull request with a description of your changes

## Code Style

- Follow the Elixir [community style guide](https://github.com/christopheradams/elixir_style_guide)
- Use `mix format` to auto-format your code
- Write clear, concise, and well-documented code

## Commit Messages

- Use present tense ("Add feature" not "Added feature")
- Start with a short summary, followed by a blank line and a detailed description if needed
- Reference related issues (e.g., `Fixes #42`)

## Community Standards

- Be respectful and inclusive
- Provide constructive feedback
- Help others and ask for help when needed

## Questions or Help?

- Check the [documentation](docs/)
- Open an issue on GitHub
- Reach out to the maintainers

We appreciate your contributions! 🚀
